# Teaching plugin

Two skills for learning a skill deliberately: plan a path, then review progress and adjust.

## Installation

In Cursor:

```bash
/add-plugin teaching
```

For other agents, copy `skills/` into the directory your agent loads.

## Components

### Skills

| Skill | Description |
|:------|:------------|
| `create-learning-path` | Build a personalized learning roadmap with milestones and practice checkpoints |
| `run-learning-retrospective` | Evaluate progress, identify blockers, and adjust the learning plan |
