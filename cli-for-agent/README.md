# CLI for Agents

One skill, `cli-for-agents`, for designing and reviewing **CLIs that coding agents drive**: non-interactive flags first, layered `--help` with examples, stdin and pipelines, fast actionable errors, idempotency, `--dry-run`, and predictable command structure.

Use it when building or refactoring a CLI, writing subcommand help, or checking whether an existing tool blocks agents (interactive prompts, missing examples, ambiguous errors).
